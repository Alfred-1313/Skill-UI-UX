# سلیقهٔ استخراج‌شده از Ciro

این پروفایل از بررسی کد پنل، ویرایشگرها و یادداشت تغییرات Ciro در نسخهٔ
[`8b892d9`](https://github.com/Alfred-1313/Ciro/tree/8b892d932be651c29ea3f17642129920d10eca1e)
به دست آمده؛ بررسی کد بوده و به معنی تست ربات زنده نیست. برای این ارتقا هیچ تغییری در
مخزن Ciro انجام نشده است.

| بخش | ترجیحی که اسکیل به پروژه‌های بعدی منتقل می‌کند |
|---|---|
| ظاهر | تم «شب»، پس‌زمینهٔ زغالی و تأکید بنفش؛ نوار کناری شناور و شیشه‌ای، کارت‌های ساده و تیره با حاشیهٔ ظریف |
| نوشته | وزیرمتن، فارسی روان، راست‌به‌چپ؛ شناسه و لینک با جهت درست و قابل کپی؛ بدون فاصله‌گذاری بین حروف فارسی |
| منو | بخش‌بندی روشن، جستجوی منو، جمع کردن نوار کناری و مشخص بودن صفحهٔ فعلی |
| موبایل | منوی کشویی، نوار پایین در صورت نیاز، فرم‌های تک‌ستونه و ردیف‌های جدولی به شکل کارت خوانا |
| حرکت | واکنش سریع به لمس، حرکت کوتاه و هدف‌دار، بدون پرش فرم و با رعایت تنظیم کاهش حرکت |
| ذخیره | حفظ جای اسکرول و فوکوس، نمایش نتیجهٔ کوتاه، تازه شدن لیست و شمارنده؛ مشخص بودن ذخیرهٔ ناموفق |
| ویرایش متن | متن فعلی قابل کپی، راهنمای متغیرها، حفظ قالب‌بندی و ایموجی، رد HTML خراب و نگه داشتن متن سالم |
| شخصی‌سازی | هر زبان و مسیر مستقل؛ خرید عادی/عمده و وضعیت/تحویل جدا؛ پیش‌نمایش مطابق ظاهر واقعی و بازگشت به پیش‌فرض |
| محتوای بلند | حالت مقاله برای پیام‌های سازگار، پیش‌فرض خاموش و با خروجی معمولی جایگزین؛ قابلیت واقعی API بررسی می‌شود |
| مدیریت | فیلترهای ترکیبی و قابل اشتراک، رفتن از شناسه به پروفایل، مسیر دقیق منو برای ادمین تازه‌کار |

رنگ بنفش و تم شب **نقطهٔ شروع** پروژهٔ تازه‌اند؛ اگر رنگ، سبک یا حالت روشن دیگری بخواهی،
درخواست جدیدت اولویت دارد. امکانات مخصوص فروش VPN، دیتابیس و زبان PHP به پروژهٔ دیگر
تحمیل نمی‌شوند. برای یک سایت مستقل، فقط سلیقهٔ مرتبط منتقل می‌شود؛ ساخت ربات یا کیف پول
به‌خودی‌خود لازم نیست.

جزئیات اجرایی و لینک شاهد هر برداشت در
[پروفایل کامل](../skills/bot-builder-style/references/design-profile.md) و قواعد ویرایش در
[راهنمای محتوا](../skills/telegram-bot-customization/references/content-editing.md) آمده‌اند.
توصیه‌های تکمیلی مثل بررسی کنتراست و بازیابی خطای ذخیره از مشاهدات جدا شده‌اند؛ داشتن یک
قابلیت در Ciro به معنی بی‌اشکال بودن همهٔ حالت‌های آن نیست.

برای استفاده، فایل نصب مربوط به ابزارت را دوباره از همین مخزن بردار. نسخه‌های
`AGENTS.md`، `GEMINI.md`، دستورهای Copilot و هر دو بستهٔ `dist/*.skill` این پروفایل را همراه دارند.
